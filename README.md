# Student Marks, Percentage and Grade

This Python project calculates a student's total marks, percentage, grade, and performance summary based on subject marks entered by the user.

## Run the program

```bash
python student_marks.py
```

## Example

```text
Enter student name: Alice
Enter number of subjects: 5
Enter mark for Subject 1: 90
Enter mark for Subject 2: 85
Enter mark for Subject 3: 80
Enter mark for Subject 4: 75
Enter mark for Subject 5: 88

--- Academic Performance ---
Student Name : Alice
Total Marks : 418.0
Percentage : 83.6 %
Grade : A
Performance : Excellent
```
